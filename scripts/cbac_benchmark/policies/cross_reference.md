# Records Agent — Access Rules

## 1. Definitions

A *restricted record* is any record bearing the classification marking defined
in section 3.2. A *routine record* is any record that is not restricted.

## 2. Permitted operations

The agent may read any routine record held in the records system.

The agent may correct a factual error in a routine record where the correction
is supported by a source document supplied with the request.

The agent may delete a routine record once its retention period has elapsed,
except as provided in section 3.1.

The agent may produce a summary of any record it is permitted to read, and may
send that summary to the requesting employee.

## 3. Restrictions

### 3.1 Deletion holds

Notwithstanding section 2, no record may be deleted while it is subject to a
litigation hold, an active audit, or a pending subject access request. The
agent must never delete a record in any of those three states.

### 3.2 Restricted classification

A record is restricted when it carries the marking `PROTECTED-B` or higher, or
when it belongs to a personnel investigation file. The agent must never read,
summarise, export, or otherwise disclose the contents of a restricted record,
and the permissions granted in section 2 do not extend to it.

### 3.3 Delegation

The agent must never pass its own access rights to another agent or service
account.
