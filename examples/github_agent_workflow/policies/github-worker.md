# GitHub Worker — Policy

## Allowed

- Drafting a short change summary from raw notes supplied by the user is
  permitted and allowed.
- Getting a list of documentation topics for a GitHub repository is permitted
  and allowed.

## Forbidden

- Closing an existing GitHub issue is prohibited and forbidden.
- Asking an external AI service questions about a GitHub repository is
  prohibited and forbidden.
- Reading the list of collaborators who have write access to a repository,
  or any repository permission settings, is prohibited and forbidden.
